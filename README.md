A broad-buyer launch sniper for pump.fun paper trading. It buys a launch in its first ten slots only when at least four distinct wallets have bought it, the creator's opening buy is small (one SOL or less), and the creator has not sold. It exits on a 15% take-profit, an 8% stop-loss, a 120-slot hold limit, or the moment the creator sells.

## Run it

```sh
node main.ts
```
